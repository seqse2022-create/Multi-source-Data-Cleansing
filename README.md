# 多源数据清洗 —— 院校专业数据整合

## 1. 要回答的问题
哪些院校是支持203日语作为考试科目

## 2. 数据
| 项 | 值 |
|---|---|
| 数据源 | 共两个 sheet：院校清单、专业信息 |
| 原始规模 | 院校清单:45行X6列(包含标题) 专业信息:25行X5列 |
| 清洗后 | 院校清单:36行 × 7列 专业信息:23行X5列|
| 最终产出 | 37行（回答了哪些院校支持203作为考试科目） |

## 3. 处理流程（六步）
1. 业务理解 → 哪些学校的应用统计专硕，外语可以选 203 日语？
2. 数据理解 → 从两个 sheet 里识别出 14 类脏数据，最影响结果的是 5 类：
- 表头不在第 1 行（前两行是合并标题）
- 院校名称带前后空格 / 混入省份（"北京大学（北京）"）
- 所在地一列两用（"北京市（100 所）"里带统计数）
- 日期三种格式混用（2026/1/5、2026-01-05、2026年1月5日）
- 「暂无/待定/—」占位符混在日期和人数列
3. 数据准备 → 42(读取) → 40(去空行) → 39(去合计行) → 36（去重复）
4. 建模 → （三态判断(明确支持,明确不支持,无数据) + 专业代码规范化）
5. 评估 →13+10+14=37（必须能加回来）
6. 部署 →python bin/run.py

## 4. 结论

全表 37 行：支持 13 / 不支持 10 / 无数据 14。

**已知的 23 所院校里**（37 − 14 无数据），支持 203 日语的有 13 所，占 56.5%。

**广东的 5 所**：支持 3（中山、暨南、惠州学院）、无数据 2（华南理工、深圳大学）、不支持 0。
但 5 所里有 2 所缺专业信息（40%），所以"已知的 3 所都支持"不能外推成"广东全部支持"。

**结论的边界**：这份数据只覆盖 37 所院校，不能代表全国；且 14 所无专业信息，
真实比例可能更高或更低。

## 5. 关键决策
| 决策 | 我选了什么 | 为什么 |
|---|---|---|
| 重复行保留哪条 | 字段最完整的那条| 重复行通常是手工补录的残缺副本，系统导出的那条字段更全|
| 合并用 left 还是 outer |outer | 专业信息表里有一所（对外经济贸易大学）在院校表里没有，outer 能把这类"数据不全但真实存在"的记录留下来|
| "暂无/待定"怎么处理 | 日期列的占位符转移到备注列再置空；人数列的保留原文| 日期必须能解析成时间；人数保留原文是因为"待定"本身是有意义的信息，删了就丢了|
| 专业代码用什么类型 |6位字符串| 一是防止 NaN 导致整数列变浮点，二是保留前导零（025200 不能变 25200）|

## 6. 踩过的坑（★ 证明真做过）
| 现象 | 根因 | 解决 |
|---|---|---|
| merge 后行数变多 |匹配键重复,触发笛卡尔积|先清洗后merge|
| 不支持数虚高（23 而非 10） | pandas 3 的 str.contains 对 NaN 返回 False，把"无数据"算成"不支持" | 用 isna() 单独判三态 |
| 支持数虚高（15 而非 13） | 院校清单没去重，"北京大学"的两条重复行各匹配上一条 203 | 合并前先去重（keep=first） |
| 序号变浮点 |整数值遇到 NaN 时 int64 装不下，pandas 自动升级成 float64|转化为Int64|
| UnboundLocalError |py局部遮蔽,局部出现赋值,在调用此变量时不会去全局找|换个变量名（局部赋值会遮蔽模块级名字）|

## 8. 已知限制
数据只统计37所院校
数据统计不全,没有分数线,报录比
数据缺失严重,不完整的数据占比高
没做增量保存,后续往表格新添数据只能不断覆盖
xlsx表格读取表头行数写死,换一个表头在其他行数的就会出现错乱
清洗高度依赖特定表格,换取其他表格结构就无法完成清洗
